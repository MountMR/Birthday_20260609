生日祝福网页使用说明

1. 打开方式
   双击 index.html 即可打开网页。

2. 密码
   当前密码是 7305。
   如果要修改密码，打开 script.js，修改第一行：
   const PASSWORD = "7305";

3. 照片
   当前网页读取 images 文件夹里的 1.jpg 到 7.jpg。
   如果要替换照片，只需要保持文件名一致：
   images/1.jpg
   images/2.jpg
   images/3.jpg
   images/4.jpg
   images/5.jpg
   images/6.jpg
   images/7.jpg

4. 音乐
   当前网页读取：
   music/RaziyaOfficial - Happy Birthday To You (小黄人版)_L (V0).mp3
   如果要换音乐，把新 MP3 放进 music 文件夹，然后打开 script.js，修改 MUSIC_FILE 后面的文件名。

5. 修改每一页文字
   打开 index.html，搜索“第1页文字”“第2页文字”等注释，就可以修改对应页文字。

6. 翻页方式
   手机：左右滑动，或点击底部箭头。
   电脑：点击底部箭头，或使用键盘左右方向键。

7. 音乐播放
   输入正确密码后会开始播放背景音乐，并循环播放。
   右上角按钮可以暂停或继续播放。

8. 第一页互动
   输入密码后进入第一页，点击蛋糕下方的香蕉按钮。
   小黄人会冲向蛋糕，20岁蜡烛会点燃，随后出现欢呼和烟花。

9. 角色元素
   当前页面包含 Bob、Kevin、Stuart、Otto、Dave、小熊 Tim、香蕉和 Gru 风格剪影。
   这些都是用 HTML/CSS 绘制的，不需要额外下载图片素材。
